阵型是《后汉稽异录外传·星命诀》中的概念，用以代替《后汉稽异录》中的兵种转职。

六大基础兵种，即刀兵、矛兵、弓兵、刀骑兵、矛骑兵与弓骑兵可以通过「变阵」应对不同的战况。这些兵种能变化为下列的阵型：

<a href='../formation_square/'>方阵</a>
<a href='../formation_circle/'>圆阵</a>
<a href='../formation_skermisher/'>疏阵</a>
<a href='../formation_phalanx/'>数阵</a>
<a href='../formation_stabber/'>锥行</a>
<a href='../formation_goose/'>雁行</a>
<a href='../formation_hook/'>钩行</a>
<a href='../formation_mysterious/'>玄襄</a>

<a href="../zizhongdui/">辎重队</a>的「武装」指令与「变阵」有共通之处，其所能变化的三个阵型类似于基础兵种阵型的方阵、数阵与雁行，但削减了机动力：

<a href='../chariot_square/'>驷乘</a>
<a href='../chariot_phalanx/'>圜营</a>
<a href='../chariot_goose/'>叠屋</a>

<a href="../gongbing/">工兵</a>的「建设」指令与「变阵」有共通之处，其所能建设的六种器械为：

<a href='../yunti/'>云梯</a>
<a href='../daoche/'>刀车</a>
<a href='../chongche/'>冲车</a>
<a href='../jinglan/'>井阑</a>
<a href='../chuangnu/'>床弩</a>
<a href='../fashiche/'>发石车</a>
