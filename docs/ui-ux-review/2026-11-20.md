- **查找路径**：消歧义回链、搜索标题带分类、标签页不进索引、首页百科区改为重点词条。
- **细节修补**：首页 h1、B 站 iframe 懒加载、英文用语中文化、手机表格溢出与横滑提示。

## 1. 网站整体设计风格

- **定位**：没变。还是游戏官网、设定百科、创作手记三合一的内容型站点。
- **视觉风格**：基调没变，还是米色纸底配近黑文字、水墨 Hero 图。细节有三处变化：
  - 按钮和分区标题统一成「两端竖条 + 线段」的框线样式，像古籍版框，风格更统一。
  - 页面标题改成半粗体，并禁止中文合成斜体。
  - 原来的无衬线字体（Inter + 系统黑体）临时换成了系统自带的宋体粗体，用粗细和正文的常规宋体区分。
- **布局与导航（有变化）**：
  - 词条页有了章节目录：宽屏在正文右侧固定显示，并高亮当前章节；窄屏在右下角悬浮。
  - 日志列表顶部加了类别和年份筛选。
  - 兵种总览和兵种词条加了兵种树卡片图，卡片下附转职条件表。卡片图在桌面上撑满整个屏幕宽度，突破了 768px 的正文栏。
- **组件**：可横滑的表格容器两侧加了淡出提示；军略词条的表格加了「前置军略 / 后续军略 / 互斥军略」几行。

## 2. 现有设计的优点

前两轮列的优点都还在。这次新增的：

| 优点 | 对用户的价值 |
|--|--|
| 章节目录：宽屏侧栏高亮当前章节，窄屏悬浮按钮 | 曹操页（桌面 4557px）可以直接跳到「登场战役」；章节能单独分享链接；跳转后标题不会被吸顶导航挡住 |
| 消歧义回链 | 从「陈到（人物）」能回到消歧义页，消歧义的两个方向都走得通了 |
| 搜索结果标题带分类 | 搜「陈到」时，三条结果分别是「兵装与宝物」「消歧义」「人物」，能直接分辨 |
| 首页百科区展示重点词条 | 首页展示的是主角和主要人物，不再是按拼音碰巧排在前面的「阿贵、AI目标」 |
| 日志筛选 | 61 篇里有 51 篇是创作手记；按类别或年份筛选后，翻页范围大幅缩小 |
| 横滑提示 | 手机上别称表（552px）两侧有淡出，用户知道还能往右滑 |
| 兵种树卡片 + 转职条件表 | 转职路线一目了然；节点和表格行悬停时联动高亮 |
| 军略词条的前置 / 后续 / 互斥军略 | 手机上不用横滑 2140px 宽的军略盘，也能查到前置军略 |

**本轮新发现**

| 编号 | 问题在哪 | 具体问题 | 对用户的影响 | 改善建议 |
|--|--|--|--|--|
| N5 | 搜索索引 | 【客观】搜「陈到」，第 4、5 条是「杵」和「长弰弓」。它们和陈到唯一的关系是页面底部「上一篇：陈到 / 下一篇：陈到」的链接，摘要里显示的也是「←上一篇 陈到下一篇→」 | 每个词条名都会把前后两个邻居词条一起搜出来，结果里噪音很多 | 给上一篇 / 下一篇、面包屑、评论区等区域加上 Algolia 爬虫的排除规则，比如在 `<nav>` 上标排除属性，或者在爬虫配置里写选择器 |
| N6 | 暗色模式下的评论区 | 【客观】暗色下评论编辑框是纯白底（`#fff`），在 `#171717` 的页面上非常刺眼；「暂无评论」是 `#444` 字配 `#171717` 底，对比度 1.84:1，几乎看不见 | 暗色用户读到页面底部会被白框晃一下，空状态提示也看不到 | 启用 Waline 的暗色支持（`dark` 选项指向 `html.dark`），或者在 `waline.css` 里用站点的主题变量覆盖面板的背景色和文字色 |
| N7 | 兵种总览页 | 【客观】<br>- 11 张兵种树卡片纵向排列，页面在桌面上 9924px、手机上 13203px。<br>- 正文只有 3 个 `section-title`，不够 4 个，所以没有出现章节目录，各基础兵种之间也没有跳转入口。<br>- 卡片容器用了 `w-screen`，宽度按 `100vw` 算，把滚动条也算了进去。在显示常规滚动条的系统上（如 Windows），页面会多出 8px 横向滚动（实测 scrollWidth 1273 对视口 1265） | 想找「骑兵」那张卡要滚很久；Windows 用户会看到一条多余的横向滚动条 | 卡片顶部放一行基础兵种的跳转链接，或者把每张卡片的标题做成 h2，让章节目录覆盖到它们；全宽布局改用不含滚动条的宽度（比如容器查询，或者在 `.wiki` 的父级上做全宽） |
| N8 | 兵种树节点 | 【客观】绿色节点（`#4C8A3A`）上的 14px 白字对比度 4.20:1，低于 4.5:1；蓝色节点 5.18:1、橙色节点 4.98:1 都达标 | 中阶兵种的名字在小字号下略难读 | 把绿色调深到 `#3F7A2E` 左右，对比度约 5:1 |
| N9 | 手机上的军略盘 | 【客观】手机上军略盘 SVG 宽 2140px，放在 295px 宽的横滑容器里（约 7 屏宽），节点文字 11px | 手机上看整体结构仍然吃力。军略词条已能直接查到前置军略，所以这是锦上添花 | 手机上提供按等级分组的列表视图，或者点击节点时只高亮它的关联节点 |

## 4. 重点改善方向

- **视觉设计**：
  - 补齐评论区的暗色模式和小字对比度（N6、#11）。
  - 兵种树的绿色节点调深（N8）。
  - 确认宋体粗体在 Windows 和 Android 上的回退效果（#15）。
- **页面布局**：
  - 兵种总览要有页内导航，并修正全宽卡片造成的横向滚动（N7）。
  - 手机上分类和音序改成 2 列（N3）。
  - 音序检索改成一行字母导航条（#8）。
- **导航与信息架构**：
  - 加全局搜索入口（#3）。
  - 清理搜索索引噪音，同名时消歧义页排第一（N5、N1）。
  - 日志类标签移出百科分类（#8）。
- **交互体验**：
  - 分类列表补充摘要（#1）。
  - 手机上军略盘提供列表视图（N9）。
- **手机端**：
  - 能力区的图表和特质表按内容区宽度缩放（N4）。
  - 吸顶导航压缩高度，并在导航里放搜索入口（N3）。

## 6. 总结

**整体评价**：这一轮的改动集中在「查找路径」上，效果明显。
- 第二轮总结里点名的 5 项中：N2 和 #5 已完全解决，N1 和 #6 基本解决；#3 全局搜索，以及第 5 项里的 N3、N4 还没有动。
- 第一轮遗留的 #7、#16 也解决了，#9、#10、#14 解决了大半。
- 词条页的使用体验提升最大，目录、消歧义回链、横滑提示、军略关系都补上了。

现在剩下的短板有三块：
- **搜索本身**：入口只在一个页面；索引里混进了导航文字，搜一个词条会带出两个邻居词条。
- **暗色模式下的评论区**：白色面板，空状态看不见。
- **新加的兵种总览**：页面太长、没有导航，在 Windows 上还会出现横向滚动。

**最值得优先改的 5 项**：

1. 搜索索引排除上一篇 / 下一篇等导航区域，同名时消歧义页排第一（N5、N1）。主要改爬虫配置，成本低、收益直接。
2. 顶栏和手机菜单加全局搜索入口（#3）。
3. 评论区跟随暗色模式，同时把小字对比度提到 4.5:1（N6、#11）。只改 `waline.css` 和初始化参数。
4. 兵种总览加基础兵种跳转条，并修正全宽卡片的横向滚动（N7）。
5. 手机端：分类改 2 列、导航压缩高度、能力区图表自适应宽度（N3、N4）。

**整体优化方向**：继续保持纸本水墨风格，不做重设计。「消歧义 → 词条 → 章节」这一段已经打通，下一阶段把起点的「搜索」做好：入口要全局可用，结果要干净。之后再把手机端和暗色模式下的边角（评论区、图表、百科首页）补齐。
