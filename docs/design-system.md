# 设计规范（Design System）

> [!NOTE]
> **这是一份持续维护的规范文档**，与 `docs/ui-ux-review/` 下的评估快照不同：样式改了就要同步改这里。

> - 整理依据：2026-11-26 `main` 分支（提交 `06848f5`）的源码，以及 [第四轮 UI/UX 评估](ui-ux-review/2026-11-24.md)。

## 1. 设计理念

**一句话**：把网页做成一册**古籍刻本**。米色纸、墨色字，用版框、界栏、鱼尾、朱印这些书籍构件来组织界面，而不是卡片、阴影、圆角。

| 关键词       | 在界面上的体现                                                                 |
| ------------ | ------------------------------------------------------------------------------ |
| 纸本、墨色   | 背景 `#F2F1EC` 米色纸，正文 `#171717` 近黑墨色；暗色模式是同一对颜色互换       |
| 线条代替体块 | 用文武线、三线表、双框分区，不用色块卡片和投影                                 |
| 直角         | 默认圆角为 0；所有框都是方正的                                                 |
| 楷体代替加粗 | 字重 ≥ 600 的地方自动换成汇文正楷，不合成粗体                                  |
| 克制的颜色   | 大面积只有纸和墨；颜色只用来表达**语义**（版本、阵营、等级、正负值），不做装饰 |
| 安静的动效   | 只有 150–300ms 的淡入淡出和底色过渡，尊重「减少动态效果」设置                  |

**三条原则**（取舍时按顺序优先）：

1. **内容优先**：这是百科 + 长文阅读站，任何装饰都不能降低可读性（对比度、字号、行距）。
2. **意象一致**：新组件先想「古籍里对应的是什么」（版框？界栏？印章？批注？），找不到对应物就用最朴素的横线 + 文字。
3. **语义着色**：颜色必须能回答「它代表什么」。只为好看而加的颜色不要加。

### 风格定位（与通用风格库对照）

用 ui-ux-pro-max 风格库对照，最接近的是 **E-Ink / Paper**（纸色底、高对比墨色、阅读优先、无投影）与 **Minimalist Monochrome**（零圆角、无投影、横线分区、反色选中态）的组合，再叠加中国古籍的装饰语汇。

风格库按「游戏百科」自动给出的方案（蓝紫配色、思源黑体 / 宋体 TC、超大字号极简主义）**不采用**：它与已经成型的刻本风格冲突，也不适合中文长文阅读。

## 2. 色彩

### 2.1 基础 token（`global.css` 的 `:root` / `html.dark`）

所有组件优先使用这几个变量；Tailwind 里对应 `text-main`、`bg-main`、`bg-muted`、`border-main`。

| Token           | 亮色      | 暗色      | 用途                               | 对比度（对 `--bg-main`） |
| --------------- | --------- | --------- | ---------------------------------- | ------------------------ |
| `--text-main`   | `#171717` | `#F2F1EC` | 正文、标题、图标、框线             | 15.85 : 1（亮暗相同）    |
| `--bg-main`     | `#F2F1EC` | `#171717` | 页面背景（纸色）                   | —                        |
| `--bg-muted`    | `#EAE9E1` | `#242424` | 悬停底色、标签底、滚动条轨道       | —                        |
| `--border-main` | `#171717` | `#F2F1EC` | 框线；与文字同色，线条就是「墨线」 | —                        |

暗色模式的切换方式：`<html>` 上加 `.dark`（`ThemeToggle.astro`），Tailwind 用 `@custom-variant dark (&:where(.dark, .dark *))`。**不用** `prefers-color-scheme` 媒体查询直接写样式。

### 2.2 墨色浓淡阶梯（`color-mix` 透明度）

次要文字、分隔线一律用 `color-mix(in srgb, var(--text-main) N%, transparent)` 从墨色派生，不另取灰色。这样亮暗模式自动成立。

| 浓度    | 用途                                              | 出处示例                                |
| ------- | ------------------------------------------------- | --------------------------------------- |
| 12%     | 吸顶导航底线                                      | `Nav.astro`                             |
| 14%     | 表格行间细线、文章邻接链接分隔线、人物小卡底线    | `.wiki-table --wiki-rule`、`.note-card` |
| 18%     | 目录左侧竖线                                      | `EntryToc.astro`                        |
| 22%–25% | 评论区边框、浮层边框                              | `waline.css`、`EntryToc.astro`          |
| 45%     | 文存题头双线                                      | `--wenyan-rule`                         |
| 62%     | 表格行标题、次要说明文字（对比度 ≥ 4.5:1 的下限） | `--wiki-label`、`--wenyan-muted`        |
| 70%     | 表头下粗线、表格收尾线、人物小卡顶线              | `--wiki-rule-strong`                    |
| 72%     | 未选中按钮文字、搜索占位文字                      | `.corner-mark`、`algolia.css`           |

**规则**：承载文字信息的颜色不低于 62%；只做分隔的线可以低到 12%。另外，`opacity-70` 用于日期、面包屑当前项、眉题等「元信息」。

### 2.3 版本色（`src/data/editions.ts` + `global.css`）

游戏有两个版本，颜色是全站最重要的语义色。版本标题、分区标题、版本小标签必须一致。

| 版本          | 文字（亮 / 暗）                      | 底色（亮 / 暗）             |
| ------------- | ------------------------------------ | --------------------------- |
| 本传 `base`   | `blue-800` = `#15559A`* / `blue-300` | `blue-100` / `blue-900`     |
| 星命诀 `dlc`  | `yellow-800` / `yellow-300`          | `yellow-100` / `yellow-900` |
| 联动 `collab` | `red-800` / `red-300`                | `pink-100` / `pink-900`     |

\* `--color-blue-800` 在 `:root` 里被改写为 `#15559A`（比 Tailwind 默认更沉稳、饱和度更低），所以全站的 `blue-800` 都是这个值。

### 2.4 功能语义色

亮色值都已调深到在纸色底**和** `bg-muted` 悬停底上 ≥ 4.5:1；暗色值是同色相的提亮版。

| 类别        | Token                                           | 亮色                                          | 暗色                                          |
| ----------- | ----------------------------------------------- | --------------------------------------------- | --------------------------------------------- |
| 数值正 / 负 | `--stat-pos` / `--stat-neg`                     | `#047857` / `#B91C1C`                         | `#34D399` / `#F87171`                         |
| 特性等级    | `--trait-top` / `--trait-super` / `--trait-bad` | `#2F6B0F` / `#2F6B0F` / `#B91C1C`             | `#7CC94A` / `#7CC94A` / `#F2606F`             |
| 关卡阵营    | `--side-blue` / `-red` / `-green` / `-yellow`   | `#1F5F99` / `#B91C1C` / `#2F6B0F` / `#7A5A00` | `#6AA8E0` / `#F2606F` / `#7CC94A` / `#FFD111` |
| 兵种阶位    | `--tier-mid` / `--tier-high`                    | `#A34A08` / `#B91C1C`                         | `#FDBA74` / `#F87171`                         |
| 百科链接    | `--wiki-link`                                   | `#2775B6`（见 §11）                           | `#6AA8E0`                                     |
| 图表        | `--chart-text-muted` / `--chart-grid`           | `#555555` / `#CCCCCC`                         | `#B5B4AE` / `#444444`                         |
| 胆识 / 冷静 | `--chart-dan`（朱砂）/ `--chart-leng`（靛青）   | `#A32D2D` / `#24507A`                         | `#E0665C` / `#6F9FD2`                         |

顶级特性（`level: 1`）额外带发光：`text-shadow: 0 0 8px <色>, 0 0 12px <色>`。这是全站唯一允许的文字阴影。

### 2.5 朱印色

| Token                     | 亮色                  | 暗色      | 用途                                          |
| ------------------------- | --------------------- | --------- | --------------------------------------------- |
| `--seal-bg` / `--seal-fg` | `#A32D2D` / `#FCEBEB` | 同左      | 悬浮按钮（回到顶部、窄屏目录），对比度 6.13:1 |
| `--wenyan-seal`           | `#A32D2D`             | `#E0807A` | 文存文末朱印、尺牍朱丝栏                      |

朱砂 `#A32D2D` 是全站唯一的「强调色」，只用在**印章**意象上，不要拿来做普通按钮或链接。

### 2.6 Tailwind 调色板的使用边界

- **可以直接用**：版本色（§2.3）、更新日志类别色（`changelog-parser.ts`，`*-800` / `dark:*-300` 成对）。
- **新代码不要用**：`text-blue-600`、`text-neutral-*`、`bg-gray-*` 这类与主题无关的灰和蓝。需要次要色用 §2.2 的墨色浓淡，需要链接色用 `--wiki-link`。
- 任何颜色都必须**同时写出暗色值**（token 里成对定义，或工具类写 `dark:` 变体）。

## 3. 字体

### 3.1 字体族

| 用途            | 字体族（Tailwind 类）                                     | 实际字体                                 |
| --------------- | --------------------------------------------------------- | ---------------------------------------- |
| 全站默认        | `font-sans` → `'Huiwen', 'Noto Serif SC Variable', serif` | 常规字重：汇文明朝；字重 ≥ 600：汇文正楷 |
| 西文标题 / 引文 | `font-serif` → `'Newsreader Variable', 'Huiwen', …`       | 西文用 Newsreader，中文仍落到汇文        |
| 文存（文言）    | `--wenyan-font` → `'Huiwen ZhengKai', 系统楷体…`          | 全文汇文正楷                             |
| 缺字回退        | `Noto Serif SC Variable`                                  | 思源宋体                                 |

注意：本站 `font-sans` 其实是**宋体（明朝体）**。整站没有无衬线字体，这是有意为之。

### 3.2 字重规则：「以楷代粗」

| 想要的效果            | 写法                                                |
| --------------------- | --------------------------------------------------- |
| 正文                  | 不写（400）                                         |
| 略强调、但保持明朝体  | `font-medium`（500）                                |
| 强调 / 标题感（楷体） | `font-semibold` / `font-bold` / `<strong>` / `<th>` |

- 字重 600 以上**不会变粗，而是换成楷体**。不想出现楷体的地方（导航、标题、选中态）用 `font-medium`。
- `html { font-synthesis-style: none; }`：中文不合成斜体。`italic` 只对 Newsreader 的西文生效。

### 3.3 字号阶梯（实际在用的）

以 Tailwind 默认刻度为准，基准 16px。手机写不带前缀的值，`sm:` 起放大。

| 层级                   | 手机 → `sm:` 及以上                  | 用在                   |
| ---------------------- | ------------------------------------ | ---------------------- |
| 页面主标题 h1          | `text-3xl` → `sm:text-5xl`           | 首页 Hero、文章页标题  |
| 站点名                 | `text-2xl` → `sm:text-4xl`           | `Header.astro`         |
| 版本标题               | `text-2xl`（24px）                   | `.edition-title`       |
| 列表标题               | `text-xl` → `sm:text-2xl`            | 日志列表 `PostPreview` |
| 分区标题               | `text-xl`（20px）                    | `.section-title`       |
| 词条列表项             | `text-lg` → `sm:text-xl`             | `ProjectPreview`       |
| 正文                   | `prose` 16px → `sm:prose-lg` 18px    | 文章、词条正文         |
| 表格                   | 15px（`0.9375rem`），表头 14px       | `.wiki-table`          |
| 元信息 / 按钮 / 面包屑 | `text-sm`（14px）                    | 日期、分页、标签       |
| 眉题、角标             | `text-xs`（12px）+ `tracking-widest` | 文章眉题               |

**下限**：可见文字不小于 12px。

### 3.4 行高与字距

| 场景          | 值                                                         |
| ------------- | ---------------------------------------------------------- |
| 正文          | Typography 插件默认（约 1.75），两端对齐 `text-justify`    |
| 文章段落      | 首行缩进 `indent-[2em]`                                    |
| 表格          | `line-height: 1.6`，数字用 `tabular-nums`                  |
| 标题          | `leading-tight`                                            |
| 文存正文      | `line-height: 2`，`letter-spacing: 0.05em`                 |
| 文存标题      | `letter-spacing: 0.15em`，并补等量 `padding-left` 保持居中 |
| 表头 / 组标题 | `letter-spacing: 0.06em` / `0.08em`                        |

### 3.5 字体子集

汇文字体只包含站内用到的字（按字频 30 字一片）。新内容出现子集外的字会显示成思源宋体，需要重新切片，流程见 `AGENTS.md`「字体」一节。

## 4. 布局

| 项目         | 值                                                                                                                                                |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| 内容栏宽度   | `max-w-3xl`（768px），导航、面包屑、页眉、`main`、页脚统一                                                                                        |
| 长文阅读宽度 | `max-w-[38em]`（日志文章，约 42.75rem），文存题头同宽                                                                                             |
| 页面左右边距 | `px-4`（16px）→ `md:px-8`（32px）                                                                                                                 |
| 断点         | 以 `sm`（640px）为主切换点；导航在 `md`（768px）以下收成汉堡菜单；手写媒体查询要用与 Tailwind 相同的 `(width < 48rem)`，不要写 `max-width: 767px` |
| 撑满视口     | `.full-bleed`：扣除 `--scrollbar-width`，**不要**直接写 `w-screen` / `100vw`                                                                      |
| 宽表格       | 放进 `.overflow-x-auto`，词条正文里会自动出现两侧淡出提示                                                                                         |
| 吸顶导航     | `z-30`，背景纸色 92% + `blur(8px)`；手机上下内边距 12px，桌面 32px                                                                                |

**层级（z-index）**：导航 30 → 悬浮按钮 1000 → 搜索全屏面板 1100。

**垂直节奏**：块与块之间用 Tailwind 的 4 的倍数（`mb-4`、`mb-8`、`mb-12`），大区块之间 `my-16 sm:my-24`。这是项目里的惯例，不是硬性刻度。

## 5. 形状与线条

这是本站风格的核心：**用线条和框表达层级，不用圆角和投影。**

### 5.1 圆角与投影

| 属性 | 默认值 | 例外                                               |
| ---- | ------ | -------------------------------------------------- |
| 圆角 | **0**  | 文存朱印 `2px`（模拟印泥边缘）；其他现存圆角见 §11 |
| 投影 | **无** | 浮层（窄屏目录弹出层）为了与正文分离，允许一层投影 |

### 5.2 线条语汇

| 名称        | 古籍出处           | 参数                                                  | 用在                                   |
| ----------- | ------------------ | ----------------------------------------------------- | -------------------------------------- |
| 文武线      | 版框的外粗内细双线 | 上 2px + 下 1px，间隔 2px，总高 5px，线色 = 文字色    | 分区标题 `.section-title`              |
| 版本框线    | 版框左右边栏       | 两端满高 3px 竖条 + 上下内缩 (3px, 7px) 的 1px 横线   | 版本标题、`Button.astro`               |
| 版本框线·小 | 同上               | 竖条 2px，内缩 (2px, 4px)                             | 版本小标签 `.edition-frame--sm`        |
| 双框        | 四周双边           | 外框 1px border + `::after` 内缩 3px 的 1px 细框      | 图标按钮 `.icon-frame`、朱印、图表气泡 |
| 三线表      | 书刊表格           | 表头下 1px（70%）、行间 1px（14%）、收尾 1.5px（70%） | `.wiki-table`、Markdown 表格           |
| 版心横线    | —                  | 上 1.5px（70%）+ 下 1px（14%），无底色                | 人物小卡 `.note-card`                  |
| 题头双线    | —                  | `3px double`（45%）                                   | 文存题头                               |
| 朱丝栏      | 尺牍笺纸           | 每行底部 1px 线，行距 2em，朱色 32%                   | 书信 / 檄文笺纸                        |
| 虚线        | —                  | `border-dashed`，1px                                  | 页脚分隔线、手机菜单面板外框           |

**线宽只用这几档**：0.5px（界格内线）、1px、1.5px、2px、3px。

## 6. 组件模式

### 6.1 标题（两级，都只用语义类）

| 层级     | 类名 / 组件                                                                       | 外观                                |
| -------- | --------------------------------------------------------------------------------- | ----------------------------------- |
| 版本标题 | `.edition-title .edition-title--{base,dlc,collab}`；`<SectionTitle edition="…">`  | 版本底色 + 版本框线，`inline-block` |
| 分区标题 | `.section-title [.section-title--{base,dlc,collab}]`；`<SectionTitle [tone="…"]>` | 无底色，下方整行文武线              |

不要在标题上另写 Tailwind 的字号、字重、颜色（`check:content` 会拦截一部分违规写法）。

### 6.2 按钮

| 类型       | 组件 / 类          | 外观                                             | 用在               |
| ---------- | ------------------ | ------------------------------------------------ | ------------------ |
| 文字按钮   | `Button.astro`     | 版本框线（墨色），`px-7 py-2.5`，悬停 `bg-muted` | 首页行动按钮       |
| 图标按钮   | `IconButton.astro` | 双框，`p-2`，悬停 `bg-muted`                     | 轮播箭头、分页箭头 |
| 悬浮按钮   | `.scroll-top` 等   | 朱印：朱底、浅色字、内缩 3px 浅色细框，`p-3`     | 回到顶部、窄屏目录 |
| 普通小按钮 | 1px `border-main`  | 直角细框，高 `h-8`                               | 分页跳转           |

### 6.3 选中 / 当前状态（三种，按用途选，不要混用）

| 模式     | 类名                     | 外观                                                   | 语义                  | 用在                           |
| -------- | ------------------------ | ------------------------------------------------------ | --------------------- | ------------------------------ |
| 鱼尾     | `.fishtail[--sm]`        | 两端「竖线 + 鱼尾」夹住文字，10×20px（小号 8×16px）    | 「当前所在 / 已筛选」 | 分页当前页、更新日志类别与筛选 |
| 「」角标 | `.corner-mark`           | 未选：淡角标 + 72% 文字；选中：反色实底 + 角标外扩 5px | 「多个形态中选一个」  | 人物形态切换 `DataToggle`      |
| 下划线   | `underline decoration-1` | 1px 下划线，偏移 2px                                   | 「当前导航项」        | 顶栏导航 `NavLink`             |

选中态通过 `aria-pressed="true"` / `aria-current="page"` 驱动样式，不要只靠 class。

### 6.4 链接

| 场景         | 样式                                                          |
| ------------ | ------------------------------------------------------------- |
| 正文链接     | 墨色 + 1px **虚线**下划线，偏移 2px；悬停变实线（`.prose a`） |
| 百科词条链接 | `--wiki-link` 蓝色（`.wiki a`）                               |
| 列表标题     | 平时无下划线，悬停出现虚线下划线，偏移 4px                    |
| 导航 / 页脚  | 平时无下划线，悬停出现 1px 实线下划线                         |

### 6.5 列表与「卡片」

本站**没有卡片组件**。列表项是「标题 + 元信息」，用横线（14%）或留白分隔；需要成组时用版心横线（§5.2）。不要引入圆角 + 投影的卡片。

### 6.6 表格

统一用 `.wiki-table`（并加 `not-prose`），修饰类：`--hover`（行悬停）、`--list`（无表头名单）、`--matrix`（不换行宽表）、`--merged`（合并格联动高亮）。悬停只改底色为 `bg-muted`，过渡 150ms。

### 6.7 标签

- 版本小标签：`editionBadgeClass()`，版本底色 + 小号版本框线。
- 文章标签：`bg-muted px-3 py-1 text-sm`，直角，悬停加下划线。

### 6.8 图表（canvas）

- 颜色从 CSS 变量读取（`useChartTheme.js`），不在 JS 里写死。
- 悬停气泡：直角双框（`drawTooltipBox.js`），外框实色、内框 60% 透明，坐标取整 + 0.5px 防虚边。
- 胆识 / 冷静：刻本界格横条（`.stat-grid`），十格为满，数值用汉字。

### 6.9 文存版式

只在 `wen-yan` 分类的文章页启用：全文汇文正楷、题头居中 + 双线、行距 2、文末朱印「文存」（竖排、旋转 -3°）。书信 / 檄文加尺牍笺纸。详见 `src/styles/wenyan.css`。

### 6.10 装饰符号

| 符号 | 用途                  |
| ---- | --------------------- |
| ◆    | 日志文末结尾符（50%） |
| ›    | 面包屑分隔（50%）     |
| 「」 | 形态切换角标          |

图标只用内联 SVG（`src/icons/`），`fill-current` 跟随文字色。

## 7. 交互与动效

| 项目         | 规范                                                                                                                                           |
| ------------ | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| 悬停反馈     | 首选「底色变 `bg-muted`」或「出现下划线」；不做放大、位移、阴影                                                                                |
| 时长         | 底色 / 透明度 150–300ms；页面级淡入（轮播）300ms；悬浮按钮出现 300–400ms                                                                       |
| 缓动         | `ease-out`（简单过渡）或 `cubic-bezier(0.4, 0, 0.2, 1)`（菜单）                                                                                |
| 焦点         | 统一写 `focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-[var(--border-main)]`                                     |
| 只在鼠标设备 | 悬停效果包在 `@media (hover: hover)` 里，避免触屏「粘住」                                                                                      |
| 状态旋转     | 只用于主题切换的太极图标：深色时 `rotate: 180deg`，由 `html.dark` 驱动，300ms `cubic-bezier(0.4, 0, 0.2, 1)`；其他图标不做旋转                 |
| 点击飘字     | 全站点击时飘出太极（`CursorClick.astro`，图形复用 `Taiji.astro`）：24px 墨色，`floatUp` 上移 100px 并淡出，1s `ease-out`；减少动态效果时不生成 |
| 减少动态效果 | 所有过渡和自动播放都要有 `prefers-reduced-motion: reduce` 的关闭分支                                                                           |
| 换页         | ClientRouter；客户端脚本在 `astro:page-load` 里初始化                                                                                          |

## 8. 第三方组件收编

外来组件必须映射到站点 token，不允许保留自带的白底 / 灰字 / 圆角风格。

| 组件         | 做法                                                                                        | 文件                     |
| ------------ | ------------------------------------------------------------------------------------------- | ------------------------ |
| Waline 评论  | 把 `--waline-*` 变量映射到 `--text-main` / `--bg-main` / `--bg-muted`；主按钮为反色         | `src/styles/waline.css`  |
| Algolia 搜索 | 覆盖 `--aa-*`（r,g,b 三元组）和前端包的 `--color-*`；暗色自己写一份（官方只认 `body.dark`） | `src/styles/algolia.css` |

`algolia.css` 里的三元组是手抄的 token 值，改 `--text-main` / `--bg-main` / `--wiki-link` 时要同步。

## 9. 无障碍底线

- 文字对比度 ≥ 4.5:1（亮暗两种模式、在 `bg-main` 和 `bg-muted` 上都要满足）；非文字图形 ≥ 3:1。
- 可见文字 ≥ 12px。
- 每页只有一个 `h1`；图片有 `alt`；纯图标按钮有 `aria-label`。
- 触控目标尽量 ≥ 44×44px，最低 24×24px。
- 不靠颜色单独传达信息：版本标签带文字，正负值带符号。

## 10. 新增样式前的检查清单

1. 这个颜色在 §2 里有没有现成 token？没有的话，它表达什么语义？亮暗两个值都定了吗？对比度算过吗？
2. 次要文字 / 分隔线是不是用了墨色浓淡（§2.2），而不是 `gray-*`？
3. 有没有用圆角或投影？能不能换成 §5.2 的线条？
4. 选中态用的是鱼尾、角标、下划线中的哪一种，语义对得上吗？
5. 需要加粗的地方，是不是想要楷体？不想要就用 `font-medium`。
6. 悬停写在 `@media (hover: hover)` 里了吗？过渡有没有 reduced-motion 分支？焦点样式是统一写法吗？
7. 全宽元素用的是 `.full-bleed` 吗？宽表格放进 `.overflow-x-auto` 了吗？
8. 改了 token 的话，`algolia.css` 的三元组、`useChartTheme.js` 的兜底值要不要同步？
