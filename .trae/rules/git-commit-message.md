使用中文 Conventional Commits，格式为 `<type>(<scope>): <摘要>`，scope 可省略。

- 百科词条、博客文章等内容变更用 `docs:`，如 `docs(bio): 补充曹操的特性说明`。
- 组件、utils、脚本、测试等代码变更用 `feat:` / `fix:` / `refactor:` / `perf:` / `test:` / `chore:`，如 `refactor(bio): 抽出持有人表格组件`。
- 摘要用简体中文，写清"做了什么"；需要时在正文写"为什么"。
- 一次提交只做一件事。
